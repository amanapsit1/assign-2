# College ERP System - Notices Feature

## Objective
The notices feature allows students to access important college announcements.

## Features
1. Students can view the latest college notices.
2. Each notice contains a title, publication date, and description.
3. Authorized staff members can publish notices.
4. Notices are displayed in chronological order.

## Acceptance Criteria
- Students can view published notices.
- Notice titles, dates, and descriptions are displayed correctly.
- Only authorized staff can publish notices.

## Testing
Verify that notices display correctly and that unauthorized users cannot publish announcements.
